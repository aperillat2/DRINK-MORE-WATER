# App Store listing — version 2.1

Paste each block into App Store Connect → the app → the version's localization (pick the
language at the top right of the version page). The app name stays **DRINK MORE WATER** in
every language. Limits: subtitle 30, keywords 100, promotional text 170, description 4000.

Keywords never repeat words from the app name (Apple already indexes them), and have no
spaces after commas.
